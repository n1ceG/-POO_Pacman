Cómo usar este checklist

Elegí un objeto y marcá cada regla cuando la consideres terminada. Los métodos compartidos se dividen en comportamientos para mostrar los avances parciales.

  • “Evidencia inicial” conserva la revisión del 27/10/2026. Cambiar una marca no reanaliza Java ni modifica Trello.
  • Exportá el avance para respaldarlo o pasarlo al grupo. Al importar se reemplazan las marcas actuales, previa confirmación.
  • Los vínculos entre objetos permiten recorrer sus colaboraciones. Las etiquetas N llevan a la tarjeta correspondiente.

El guardado del navegador depende de la PC, el perfil y la ubicación del archivo. La exportación JSON es la copia portable de tus marcas.
